## 📈 ANALYTICS TO TRACK (Weekly Review)

### YouTube

```
📊 METRICS:
- Views: target 100+ views first week
- Watch time (hours): target 10+ hours first week
- Retention (%): target >50% average view duration
- Clicks (via CTR): target >2% (click through to AppStore)
- Comments: engage within 24h, thank for shares
- Likes: aim for 5-10% like rate
- Subscribers: track gain

🎯 RED FLAGS:
- Drop below 50% retention at X minute → check pacing
- 0% CTR → CTA not clear, re-check link placement
- Negative comments → address with empathy & link to support

📝 ACTION ITEMS:
- If retention drops at timestamp X, add more dynamic B-roll
- If CTR low, add pinned comment with link
- If comments high but negative, create FAQ follow-up video
```

### TikTok

```
📊 METRICS:
- Views: target 1000+ per post
- Engagement rate (shares + likes + comments): target >3%
- Profile visits: target 10% of views → profile
- Saves: high = content is useful
- Shares: high = organic reach explosion

🎯 RED FLAGS:
- <500 views after 24h → audio choice wrong, repost with trend audio
- >10% traffic from non-Algeria → consider geo-targeting

📝 ACTION ITEMS:
- High engagement video? Immediately create follow-up
- Trend audio changing? Monitor & adapt quick
- Low engagement? Try with different hook or audio
```

### LinkedIn

```
📊 METRICS:
- Impressions: target 500-1000
- Engagements (likes + comments): target 50+
- Click-through rate: target >1%
- Shares: target 5+ shares (viral multiplier)

🎯 RED FLAGS:
- <100 impressions after 48h → audience too small, founder should tag people
- 0% shares → tone too sales-y, re-balance

📝 ACTION ITEMS:
- Encourage team to like & comment first (algorithm boost)
- Pin top comments that drive CTR
- Tag new investors/partners in comments (grow audience)
```

### App Installs (Master Metric)

```
📊 METRICS (via Firebase Analytics or App Store Connect):
- Installs (attributed to campaign): target 100+ first week
- Source breakdown (YouTube, TikTok, LinkedIn, email): track %
- Signup rate (installs → account): target >20%
- Retention (day 1, day 7): target >50%

💰 ROI CALCULATION:
If Cost = $1000 (production + promotion)
If Acquired = 100 users at >20% retention
→ Cost Per User = $10 (reasonable for consumer app)

🎯 RED FLAGS:
- >5% uninstall rate in first 24h → onboarding issue
- Installs → signup <15% → friction in signup flow

📝 ACTION ITEMS:
- If CAC high, boost successful traffic sources
- If retention low, investigate first-time user flow
```

## 🚨 CRISIS MANAGEMENT

**If negative feedback appears**:

5. Create FAQ video addressing the concern (transparency wins)

**If video underperforms** (low views after 48h):
1. Don't panic (YouTube algorithmic boost can take 72h+)
2. Re-share on all platforms with fresh text
3. Ask team to share on personal networks (social proof)
